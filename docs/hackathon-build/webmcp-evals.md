# WebMCP evaluations

Use [current acceptance scenarios](../WEBMCP.md#acceptance): gated evidence,
context/version correctness, stale response/citation rejection, research
idempotency, reset/cancellation, privacy canaries and manual fallback.
Tests live in `apps/admin/src/webmcp/` and backend integration/privacy suites.
A pass requires both the correct tool result and matching visible state.
