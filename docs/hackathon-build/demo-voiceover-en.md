# WebMCP demo voiceover master — historical

Published video: [YouTube](https://youtu.be/O5nXMNo9o20). Retained as a reusable
creative asset, not instructions for agent startup. Target 50–54 seconds at
145–152 words/minute, with two-second head/tail room. Pronounce CliDeck “Cli Deck”,
WebMCP “Web M C P”, IOS XE “I O S X E”, C9300 “C ninety-three hundred”.

An answer can look right. In network operations, the wrong version is the
wrong answer.

CliDeck MCP turns raw device evidence into a version-aware case for an engineer
and a browser agent. Files stay local. Only a selected window is shared, after
secrets are redacted and the engineer gives consent.

CliDeck detects the platform, operating system, and release, then searches
active knowledge for procedures, limitations, and verified provenance.
Nearby-version guidance is labelled as a reference; compatible guidance is
shown as a match.

Through six typed WebMCP tools, the agent reads approved evidence, searches the
current case, and places its interpretation beside the official result. Every
change creates a new case version, so stale responses cannot overwrite new
evidence.

People keep control. Agents gain precise capabilities. Answers stay
inspectable, current, and grounded in sources.

That is CliDeck MCP.

For a new recording: continuous delivery without click/scene references;
prefer 48 kHz lossless WAV, no music/reverb/limiting in the voice master.
